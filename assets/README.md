# 추첨 기록 초기 데이터

- 출처: [동행복권 추첨결과](https://www.dhlottery.co.kr/lt645/result)
- 원본: 사용자가 위 페이지에서 내려받아 제공한 `로또 회차별 당첨번호_20261104230259.xlsx`
- 범위: 제1회~제1248회, 누락·중복 없이 1,248건
- 필드: 회차, 본번호 6개, 보너스. 원본에 추첨일 열이 없어 날짜를 생성하지 않았다.
- 검증: 정수 여부, 1~45 범위, 본번호 6개 중복 없음, 보너스와 본번호 중복 없음, 연속 회차.
- 원본 SHA-256과 출처 URL은 `draws.json` 메타데이터에 기록했다. 원본 XLSX 자체는 저장소에 포함하지 않았다.

재생성: `python tool/import_draws.py 원본.xlsx assets/draws.json`

앱은 JSON 번들을 검증한 뒤 로컬 캐시에 적재하며, 새 회차만 원격 조회한다. 이 파일은 최초 실행 시 오프라인에서도 직전 회차·미출현 규칙을 사용할 수 있게 한다.
