## 확정: 추천 홈의 세 상태

아래 세 상태는 서로 다른 화면이 아니라 같은 추천 홈의 표시 상태다. 모든 상태에서 게임 수 1~5를 선택할 수 있다. 생성 방식 카드의 테두리 또는 배경색으로 선택 여부를 표시한다.

| 상태 | 본문 | 하단 주요 버튼 | 이동 |
|---|---|---|---|
| A. 완전 랜덤 선택 | 상세 조건 없이 생성한다는 짧은 안내 | `번호 생성` | 선택한 게임 수만큼 완전 랜덤으로 생성 → 추천 결과 |
| B. 상세 설정 선택, 저장 이력 없음 | 아직 저장된 상세 설정이 없다는 안내 | `설정 만들기` | 상세 설정 편집 |
| C. 상세 설정 선택, 저장된 설정 있음 | 선택 필드와 선택한 설정의 조건 요약 | 선택 전에는 비활성, 선택 후 왼쪽 `설정 수정`, 오른쪽 `번호 생성` | 설정 수정 → 선택한 설정 편집 / 번호 생성 → 선택한 설정으로 생성 → 추천 결과 |

- 생성 방식 카드 선택만으로 상세 설정 화면을 열거나 번호를 생성하지 않는다.
- 저장된 설정이 있더라도 완전 랜덤을 선택하면 A 상태다.
- 완전 랜덤으로 생성해도 저장된 상세 설정은 보존한다.
- 모든 상세 옵션이 기본값이어도 사용자가 저장한 설정이라면 C 상태로 취급한다.
- 저장된 설정은 이름으로 구분한다. 홈에는 현재 선택한 설정 이름과 주요 조건 요약을 표시한다.
- 상세 설정 카드 아래에는 한 줄짜리 선택 필드를 둔다. 저장된 설정이 없으면 비활성 상태로 `저장한 설정이 없습니다`, 저장된 설정이 있으나 선택값이 없으면 `설정 선택`, 선택 후에는 해당 설정 이름을 표시한다.
- 선택 필드를 누르면 바텀 시트에서 저장한 설정을 라디오 목록으로 보여준다. 목록을 홈에 항상 펼쳐 놓지 않으므로 설정 수가 늘어나도 화면이 지나치게 길어지지 않는다.
- 바텀 시트의 각 행에는 설정 이름과 주요 조건 요약을 표시하고, 하단에 `새 설정 만들기`를 제공한다.
- 번호 생성 전에는 기존 기획서의 입력·데이터·조건 충돌 검증을 수행한다. 생성에 성공한 경우 결과 화면으로 이동한다.

## 수정 와이어프레임에 반영할 배치

- 상세 설정의 고정 하단 버튼: `설정 저장`, `번호 생성`.
- `초기화`는 상세 설정의 스크롤 내용 맨 아래에 배치.
- 홈 우측 상단의 용도 없는 점 세 개 메뉴 제거.

## 확정: 추천 결과의 개별 번호 저장 아이콘 정렬

- 각 결과 카드의 번호 6개와 하트 6개는 같은 너비의 6열 배치를 공유한다.
- 하트의 가로 중심을 바로 위 해당 번호의 가로 중심에 맞춘다. 하트를 누르면 해당 번호의 `내 번호` 저장 상태를 토글한다.
- 조합 전체를 저장하는 `조합 저장` 버튼은 번호·하트의 6열 바깥에 배치하여 하트가 오른쪽으로 밀리지 않게 한다.
- 이 수정은 하트의 위치에 관한 것이다. 번호 자체를 누르는 새 저장 방식으로 대체하라는 요청이 아니다.

## 확정: 상세 설정 이름 저장

- 처음 `설정 저장`을 누르면 이름 입력 대화상자를 표시한다.
- 이름을 비워 두면 사용되지 않은 가장 작은 번호를 사용해 `설정1`, `설정2`처럼 자동 저장한다.
- 대화상자 제목은 `설정 저장`, 입력 레이블은 `설정 이름`으로 한다. 입력칸에는 이번에 적용될 자동 이름 `설정N`을 미리 채워 바로 수정할 수 있게 한다.
- 입력창 아래에는 `이름은 나중에 변경할 수 있습니다.`만 표시한다.
- 저장된 설정의 이름은 설정 선택·관리 화면에서 수정할 수 있다.
- 앱에서 `조합`은 생성된 번호 6개 한 게임을 뜻하므로 추천 조건 모음에는 `설정`이라는 용어를 일관되게 사용한다.
- `설정 저장` 후에는 상세 설정 화면에 그대로 머물고 `설정을 저장했습니다.`라는 짧은 완료 메시지만 표시한다. 상단 뒤로가기를 눌러 기존 추천 결과로 돌아간다.
- 설정을 저장하지 않은 채 `번호 생성`을 누를 수도 있다. 이때 결과 화면에는 `임시 설정`과 `저장되지 않은 설정입니다.`를 표시한다.

## 확정: 결과 화면에서 설정 이동

- 적용된 설정 이름과 조건 요약을 먼저 표시하고, 그 아래 별도 행에 왼쪽 `다른 설정 선택`, 오른쪽 `설정 수정`을 나란히 배치한다.
- `다른 설정 선택`은 저장된 상세 설정이 2개 이상일 때만 활성화한다.
- `설정 수정`은 현재 사용한 설정의 편집을 뜻한다. `조합 수정`은 생성된 번호 여섯 개를 직접 바꾸는 기능처럼 읽히므로 사용하지 않는다.
- 임시 설정 결과에서는 오른쪽 버튼을 `설정 수정·저장`으로 표시한다. 이 버튼과 저장된 설정의 `설정 수정`은 결과를 유지한 채 편집 화면으로 이동하므로 경고를 표시하지 않는다.
- 결과 화면에서 뒤로가기 또는 `다른 설정 선택`으로 실제 이탈할 때 미저장 번호나 조합이 있으면 다음 대화상자를 표시한다.

  - 별도 제목 없음
  - 내용: `이 화면을 나가면 저장하지 않은 결과는 사라집니다. 저장할 번호가 있다면 결과로 돌아가 저장한 후 이동하십시오.`
  - 버튼: `결과로 돌아가기`, `저장하지 않고 이동`

- 이동을 선택하면 미저장 결과만 삭제한다. 하트로 저장한 내 번호와 `조합 저장`으로 저장한 조합은 유지한다.
- `설정 수정`은 현재 사용한 설정의 편집 화면으로 이동한다.
- `다른 설정 선택`은 저장된 설정 목록을 열며, 사용자가 다른 설정을 고르고 `이 설정으로 생성`을 눌러 새 결과를 만든다.

## 확정: 기존 결과를 새 번호로 교체

- 상세 설정 화면의 `번호 생성`과 추천 결과의 `다시 생성`은 기존 결과가 있을 때 같은 확인 대화상자를 사용한다.
- 첫 번호 생성처럼 교체할 결과가 없으면 안내 없이 생성한다.
- 제목: `새 번호를 생성하시겠습니까?`
- 내용: `새 번호를 생성하면 저장하지 않은 현재 결과는 사라집니다. 저장할 번호가 있다면 결과로 돌아가 저장한 후 다시 시도하십시오.`
- 버튼: `기존 결과로 돌아가기`, `새 번호 생성`
- 새 번호 생성을 선택해도 이미 저장한 내 번호와 조합은 유지한다.
- 반복 생성 때마다 확인이 과도하다는 사용성 피드백이 확인되면, 이전 결과 1회 복원이나 세션 단위 `다시 묻지 않기`를 후속 개선으로 검토한다.

결과는 생성 당시 설정을 기준으로 표시한다. 설정만 수정·저장한 뒤 기존 결과로 돌아오면 `생성 후 설정이 변경되었습니다.`라고 알린다. 임시 설정의 내용은 바꾸지 않고 이름만 붙여 저장했다면 결과의 `임시 설정` 표시는 저장된 설정 이름으로 바꾼다.

## 하단 내비게이션 원칙

상세 설정 화면은 추천 홈에서 진입한 편집 단계이므로 하단 내비게이션을 숨기고 상단 뒤로가기를 제공한다. 편집 중 다른 탭을 잘못 눌러 빠져나가는 것을 막고, 작은 화면에서 설정과 고정 하단 버튼의 공간을 확보하기 위한 선택이다. 뒤로가기로 이탈할 때 저장하지 않은 변경이 있으면 별도 확인을 표시한다.

추천 결과도 같은 흐름의 하위 화면이므로 최종 화면 체계에서는 하단 내비게이션을 숨기는 편이 일관적이다. 결과 하단에는 왼쪽 `다시 생성`, 오른쪽 `복권 용지에 저장`을 배치한다. `복권 용지에 저장`은 저장할 기존 용지를 선택하거나 새 용지를 만드는 흐름으로 연결한다.

상세 설정 화면의 `번호 생성`은 현재 편집값으로 결과를 생성하지만 설정을 자동 저장하지 않는다.
