# 번호 관리·설정 이름·디자인 적용 정책 수정

2026-11-09 사용자 피드백과 최종 승인 기준이다. 기존 배지·간격 문서와 충돌하는 부분은 이 문서를 우선한다. 2026-11-15 요청으로 GitHub 업로드와 `0.1.7-preview` APK 빌드·다운로드 검증을 완료했다. [APK 다운로드와 설치 정보](android-device-checklist.md#최신-업데이트-apk-017-preview)를 참고한다.

## 내 번호 관리와 하트

- 내 번호 목록의 삭제 대상 선택은 제거한다. 번호 영역 비율은 유지하되 목록은 왼쪽부터 배치한다.
- `내 번호 추가·삭제` 한 버튼으로 관리 팝업을 연다.
- 팝업의 초안은 기존 내 번호 전체로 시작한다. 선택 상태는 **일반 번호**와 **선택한 내 번호** 두 가지뿐이다. 선택 시 하트와 강조 테두리를 함께 표시하고, 다시 누르면 둘 다 없앤다.
- 이 결합 상태는 관리 팝업에만 적용한다. 조합 추가 등 다른 화면의 저장 여부와 현재 선택 여부는 계속 독립적으로 표시한다.
- 설명은 `터치로 '내 번호'를 추가 및 삭제할 수 있습니다.`이다. 확인 시 전체 초안을 한 번에 저장하며, 전부 해제한 빈 집합도 저장할 수 있다. 취소는 저장하지 않는다.
- 하트는 고정 붉은색 `#C62828`, 배지 바탕은 흰색, 배지 테두리와 번호 선택 테두리는 강조색이다. 배지 크기는 기존 확대 크기를 유지한다.

## 번호 영역·버튼·간격

- 세로 비율은 좌 7.5% / 중앙 85% / 우 7.5%로 유지한다. 가로는 좌 9% / 중앙 82% / 우 9%로 변경한다.
- 조합 추가의 선택 번호 미리보기는 이 규칙에서 제외한다. 번호들을 내용 크기에 맞춘 중앙 묶음으로 표시하며, 세로는 제목 아래, 가로는 제목 오른쪽에 둔다.
- 추천 결과의 다른 설정 선택·설정 수정은 테두리 버튼이다. 충분한 폭에서는 가로 2열, 좁은 폭 또는 큰 글자에서는 세로로 전환한다.
- 버튼 문구는 공백 단위로 줄바꿈하고 각 줄은 중앙 정렬한다. 한 단어 자체가 가용 폭보다 길 때만 일반 글자 단위 줄바꿈을 허용한다. IntrinsicWidth를 사용하는 대화상자에서도 동작하도록 실제 제약 폭에 맞춰 레이아웃한다.
- 가로 보관함의 제목 영역은 56dp에서 40dp로 줄이고, 고정 조합 작업 영역의 위 패딩은 12dp에서 6dp로 줄인다.
- 조합 카드 번호 줄 아래 내부 여백을 늘려 상단 텍스트·체크박스의 시각적 여백과 맞춘다. 복권 용지 이름 왼쪽 패딩은 12dp에서 16dp로 늘린다.

## 생성 이력과 표시 이름

- 각 게임에 생성 당시 방식과 설정 이름을 보존한다. 번호의 동일성·중복 판정은 여전히 번호 6개만 비교한다.
- 저장한 설정과 다른 조건을 저장하지 않고 생성한 경우는 `임시 상세 규칙`으로 표시한다. 저장한 설정과 조건이 같으면 그 설정 이름을 복사한다. 이후 설정 이름 변경·삭제가 과거 게임의 표시 이름을 바꾸지 않는다.
- 추천 결과 → 조합 저장·용지 저장, 조합 추가의 직접 선택·완전 랜덤·상세 규칙, 기존 조합 불러오기, 용지 게임 순서 변경에서 이력을 함께 전달한다.
- 저장한 조합 카드는 상세 규칙이라는 일반 문구 대신 보존한 이름을 사용한다.
- 용지 카드는 `3게임 · 균형 조합`, 여러 표시 이름이 있으면 `3게임 · 균형 조합 외 1개`처럼 표시한다. 대표 이름은 첫 게임 기준이며 N은 추가 표시 이름의 종류 수다. `혼합 조합`이라는 포괄 문구는 사용하지 않는다.
- 예전 저장한 조합에서 이름이 없으면 `상세 규칙`, 용지의 생성 이력 자체가 없으면 `기록 없음`으로 표시한다. 번호 일치만으로 과거 생성 방식을 추정하지 않는다.

## 저장소 호환

- SQLite 스키마를 1 → 2로 올린다. number_sets에 생성 당시 설정 이름, lottery_paper_games에 생성 방식과 설정 이름을 추가한다.
- 기존 번호·조합·용지·순서·옵션·환경 설정을 보존한 채 열만 추가한다. 기존 SharedPreferences 자동 이관 정책과 원본 보존은 유지한다.
- 용지 JSON 호환 형식은 기존 games 배열을 유지하고 같은 순서의 origins 배열을 추가한다. 게임 순서를 바꾸면 생성 이력도 같은 게임과 함께 이동한다.

## 디자인 적용과 랜덤

- 상위 적용 방식은 기본 디자인·용지별 디자인 두 개다. 각 하위 디자인 목록 마지막에 열 때마다 랜덤을 둔다. 별도 랜덤 범위 라디오와 기본 디자인 사용 항목은 제거한다.
- 개별 지정이 없으면 기본 디자인(랜덤 포함)이 미리 선택되어 보인다. 단순히 화면을 열거나 저장했다는 이유만으로 개별 복사본을 만들지 않는다.
- 기본 디자인 아래에 굵은 `용지별 디자인 덮어쓰기 여부` 제목과 유지하기·덮어쓰기 두 버튼, 각각의 설명을 둔다. 신규 기본값은 유지하기다.
- 유지하기는 개별 고정·랜덤 설정을 우선하며 나머지 용지에 기본값을 적용한다. 덮어쓰기는 기본 고정·랜덤 값을 전체에 우선 적용하되 개별 정보는 삭제하지 않는다. 유지하기로 되돌리면 개별 정보가 다시 적용된다.
- 전체 덮어쓰기 중 용지별 값을 편집하면 보존만 하고, 유지하기로 전환해야 표시된다는 안내를 제공한다.
- 예전 전역 랜덤·개별 랜덤과 기본 모드의 기존 예외를 읽을 수 있다. 명시적으로 새 정책으로 편집·저장하기 전까지 이전 적용 상태를 보존한다. 과거 간격 넓게 값은 기존 정책대로 흑백 기본으로 읽는다.

## 스타일 초기화

- 번호 크게 보기 → 스타일 변경 메뉴에 스타일 초기화를 추가한다.
- 굵은 제목으로 초기화 영역(배경 이미지 / 번호 칸 디자인 / 전부)과 초기화 범위(개별 용지 / 모든 용지)를 구분하고 각 영역에서 하나씩 고른다. 기본 선택은 번호 칸 디자인·개별 용지다.
- 개별 번호 초기화는 해당 용지의 고정·랜덤 지정을 삭제하고 현재 기본값을 상속한다. 전체 번호 초기화는 기본·개별·랜덤·덮어쓰기 설정을 초기화하고 컬러 기본으로 복원한다.
- 배경만 선택하면 번호 설정은 유지한다. 배경 변경은 아직 업데이트 예정이며, 저장된 배경 값이 없는 경우 초기화할 배경 값도 없음을 안내한다. 원본 사진 파일은 삭제하지 않는다.
- 실행 전 선택한 영역·범위에 맞는 경고를 표시한다. 전체 번호 초기화에는 기본 디자인과 모든 용지별 번호 칸 디자인 설정이 지워진다는 내용, 컬러 기본으로 복원한다는 내용과 되돌릴 수 없다는 내용을 포함한다.
- 번호·저장한 조합·용지 내용은 스타일 초기화 대상이 아니다. 배경만 초기화할 때 현재 표시 중인 랜덤 번호 디자인을 다시 추첨하지 않는다.

## 검증과 다음 기기 확인

로컬 검증 결과: 전체 자동 테스트 120개 통과, 정적 분석 이상 없음, Dart 포맷 및 `git diff --check` 통과. 최종 생성 이력 분류 수정 후 관련 추천·정책 테스트 25개도 재통과했다. GitHub Actions에서도 정적 분석·120개 테스트·APK 빌드가 성공했다. 다운로드한 APK의 버전·패키지·기존 인증서·정렬과 ZIP 무결성·artifact digest 일치를 확인했다. 실제 기기 업데이트 설치·실행은 아직 진행하지 않았다.

번호 관리 팝업의 두 상태·빈 집합 저장·취소, 가로 82%와 미리보기 예외, 단어 단위 줄바꿈, 설정 이름 스냅샷과 SQL 업그레이드, 개별 상속·덮어쓰기 복원·각 범위 초기화, 큰 글자·좁은 화면을 자동 검증한다.

실제 기기에서는 긴 설정 이름, 단어 줄바꿈, 팝업 선택·해제, 기본/개별 랜덤과 유지/덮어쓰기 왕복, 개별·전체 초기화 경고를 확인한다. 자동 테스트는 기기에서의 시각적 확인과 업데이트 설치 검증을 대신하지 않는다.
