# 2차 피드백: 테마·스타일·안내·임시 배너

2026-11-06 사용자 확정 사항을 반영한 소스 변경이다. 이 문서가 기존 스타일·광고·안내 정책보다 우선한다. 이번에는 APK를 생성하거나 GitHub에 push하지 않는다.

## 안내와 출처

- 용지 선택의 물음표는 타이머 툴팁 대신 설명 대화상자를 연다. 바깥 영역·확인·뒤로가기로 닫기 전까지 유지한다.
- 설명은 `이미 5게임이 채워진 복권 용지는 이 화면에 표시되지 않습니다.`를 먼저 표시하고, 기존 자리 부족 안내를 이어서 표시한다.
- 결과 소실 안내의 다시 보지 않기는 이동 여부와 별개다. 체크 후 결과로 돌아가기·이동·바깥 영역·뒤로가기로 닫아도 저장한다. 최종 체크가 해제되어 있으면 생략을 저장하지 않는다. 임시 설정·덮어쓰기·삭제 확인에는 적용하지 않는다. 더보기의 다시 켜기는 유지한다.
- 추천·더보기 모두 `N회 기준 · 출처 - 동행복권` 형태를 사용한다. 출처 부분만 공식 메인 사이트 링크이며, 저장 건수는 노출하지 않는다. 기준 회차는 보유 데이터에서 계산한다.

## 앱 테마

- 더보기의 앱 테마 드롭다운: 밝게·어둡게·기기 설정. 초기값은 기기 설정이다.
- 선택은 즉시 적용하고 `appTheme.v1`로 SQLite 메타데이터에 보존한다. 기기 설정은 OS의 밝기 변경을 따른다.
- 번호 크게 보기와 기본·간격 넓게·카드형 미리보기는 앱 색상 테마를 따른다. 숫자·테두리·바탕은 테마의 대비 색상을 사용한다.
- 테마 변경은 번호·용지 내용·용지별 스타일을 바꾸지 않는다.

## 스타일 변경 두 단계

- 번호 크게 보기의 `보기 스타일`을 `스타일 변경`, `용지 편집`을 `용지 내용 편집`으로 바꾼다.
- 첫 단계에는 기존 기본·간격 넓게·카드형 및 기본/용지별/랜덤 적용 방식을 유지한다. 기존 스타일 값은 버리지 않는다.
- 하단 좌측은 `스타일 상세 설정`, 우측은 `변경 완료`이다. 완료는 저장 후 크게 보기로 돌아간다. 미저장 상태의 뒤로가기는 확인하며 취소하면 초안을 유지한다.
- 상세 설정은 팝업 메뉴로 `배경 이미지 변경`, `번호 칸 디자인 변경`을 제공한다. 각 항목은 팝업을 닫고 `업데이트 예정입니다`를 약 3초 표시한다. 이 단계에서 스타일을 저장하거나 다른 편집 화면으로 이동하지 않는다.
- 실제 배경·번호 칸 편집, 사진첩 접근·권한 요청은 구현하지 않는다. 향후 제공자 디자인과 사용자 사진첩의 배경 이미지 선택을 추가할 수 있는 입구만 마련한다.

## 랜덤 범위

- 열 때마다 랜덤에서 전체 용지/현재 용지 중 하나를 라디오 버튼으로 고른다. 중복 선택은 허용하지 않는다.
- 전체 랜덤은 모든 용지에 우선 적용한다. 기본·개별 스타일 및 개별 랜덤 지정은 보존한다.
- 현재 용지 랜덤은 해당 ID에만 적용한다. 다른 용지는 기존 기본/용지별 방식을 따른다. 기존에 다른 용지를 개별 랜덤 지정했다면 그 지정도 유지한다.
- 전체 랜덤에서 현재 용지로 전환하면 전체 랜덤 직전의 기본/용지별 방식으로 복귀하고 현재 용지만 랜덤을 적용한다.
- 현재 용지의 랜덤을 해제하면 저장해 두었던 고정 스타일을 다시 사용할 수 있다. 랜덤 디자인 선택은 크게 보기 진입당 한 번만 수행하고 테마 변경·토글 조작으로 다시 추첨하지 않는다.
- 기존 `display.v1`은 계속 읽는다. 추가 필드는 `randomPapers`와 `beforeRandomMode`이다. 과거 전역 랜덤에 직전 모드 정보가 없으면 기본 모드로 복귀한다.

## 임시 광고

- 로컬 생성 이미지 3종을 `assets/test_ads/`에 보관한다. 각 화면 진입에 따라 번갈아 표시하며 자동 전환 타이머는 사용하지 않는다.
- 모든 일반 화면에서 상태 표시줄 아래·화면 제목 위에 높이 50dp 배너를 표시한다. 보관함의 중첩 화면에서는 중복 배너를 피한다.
- 팝업 안에 새 배너를 넣지 않으며 기존 화면 배너도 모달 배리어 뒤에 위치한다.
- `테스트 광고 · 실제 광고가 아닙니다`를 표시하고 클릭 동작을 제공하지 않는다. 실제 광고 SDK·추적·외부 링크·광고용 네트워크 요청은 없다.

## 다음 기기 확인 범위

1. 물음표 설명을 천천히 읽은 뒤 바깥 영역·확인으로 닫아 본다.
2. 다시 보지 않기를 체크하고 결과로 돌아온 후 재시도한다. 더보기에서 안내를 다시 켠다.
3. 밝게·어둡게·기기 설정을 선택하고 앱 재실행·OS 테마 변경을 확인한다.
4. A·B·미지정 C 용지의 스타일이 유지되는지, 전체 랜덤과 현재 용지 랜덤 전환·해제를 확인한다.
5. 상세 설정의 두 메뉴가 안내만 표시하고 기존 스타일을 바꾸지 않는지 확인한다.
6. 작은 화면·큰 글자·가로 화면에서 배너가 제목·하단 버튼을 가리지 않고 한 번만 표시되는지 확인한다. 번호 크게 보기의 가독성도 확인한다.

이번 변경은 기존 2차 APK에 포함되어 있지 않다. 새 APK 생성은 별도 요청 후 진행한다.
