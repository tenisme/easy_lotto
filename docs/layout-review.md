# 2026-11-07 테마 선택·번호 디자인·보관함 개선

사용자 확인 답변과 추가 요청을 반영한다. 이 문서는 이전 테마·스타일·배치 문서보다 우선한다. 구현·테스트 후 2026-11-07 사용자 APK 요청에 따라 `0.1.4-preview`를 생성한다.

## 테마 페이지

- 더보기의 `앱 테마 설정 >`에서 별도 페이지로 이동한다.
- 밝게·어둡게·기기 설정을 라디오 버튼과 작은 배경/강조색 목업으로 보여준다. 기기 설정은 양쪽 밝기 목업을 표시한다.
- 선택은 초안이다. `저장` 후 앱에 적용·영구 저장하며, 뒤로가기는 미저장 선택을 버릴지 확인한다. 취소하면 선택을 유지하고, 버리고 나가면 기존 적용 테마를 유지한다.

## 스타일 진입·표시

- 크게 보기의 `스타일 변경`은 메뉴를 연다. `번호 칸 디자인 변경`은 기존 디자인 설정 화면으로, `배경 이미지 변경`은 약 3초 업데이트 예정 안내로 연결한다.
- 중복된 `스타일 상세 설정` 버튼은 제거한다. 번호 디자인 화면의 완료 버튼은 `변경 완료`이다.
- 디자인 선택을 전체 문구가 줄바꿈되는 라디오 목록으로 바꾼다. 설명은 한 줄로 자르거나 말줄임하지 않는다.
- 기본 디자인, 용지별 지정, 전체/현재 용지 랜덤 적용 정책은 유지한다. 전체 랜덤에서 현재 용지로 바꾸면 직전 기본/용지별 정책으로 복귀하며, 별도로 지정했던 다른 용지의 개별 랜덤은 보존한다. 범위 축소 설명을 표시한다.

## 네 디자인과 저장값 호환

| 새 항목 | 저장 식별자 |
| --- | --- |
| 컬러 기본 | colorBasic |
| 컬러 카드 | colorCards |
| 흑백 기본 | basic |
| 흑백 카드 | cards |

새 설정 기본값은 컬러 기본이다. 이전 basic과 spacious는 동일한 흑백 기본으로 읽으며, cards는 흑백 카드로 유지한다. spacious는 UI·enum·랜덤 후보에 남기지 않는다. 이전 데이터는 읽을 때 매핑하고 다음 스타일 저장 시 새 식별자로 기록한다. 용지별 지정과 랜덤 범위는 보존한다.

공식 결과 화면의 실제 번호 배경색 CSS를 사용한다(2026-11-07 확인). 추상 색상 변수와 실제 클래스 속성값이 달라 클래스의 활성 background-color 값을 따른다.

## 번호 배치·임시 테스트

- 숫자 글자보다 원/카드의 가로·세로가 같은 틀을 먼저 만든다. 1자리와 2자리 모두 동일한 크기이며 글자는 중앙 정렬한다.
- 크게 보기의 게임 A~E 제목도 중앙 정렬한다. 정렬 선택 옵션은 없다.
- 가용 폭과 실제 확대 글자 측정으로 열 수를 정한다. 6, 4, 3, 2열만 허용하므로 줄 배치는 6 / 4+2 / 3+3 / 2+2+2 중 하나다. 5+1은 없다.
- 마지막 줄도 같은 칸 폭과 간격으로 중앙 정렬한다. 가로 화면에서는 칸 폭을 균등 분배한다.
- 아주 큰 확대에서 두 칸도 들어가지 않으면 글자를 축소하거나 깨뜨리는 대신 2열을 유지한 가로 스크롤을 제공한다. 세로 내용도 스크롤 가능하다.
- 크게 보기 제목 우측 `확대 테스트`는 글자 100~300%, 표시 폭 100~50%를 임시 조정한다. OS 설정이나 저장 데이터는 바꾸지 않으며, 초기화 또는 화면 재진입 시 원래대로 돌아간다. OS 확대 동작을 완전히 재현하는 도구는 아니다.

## 보관함

- 복권 용지 → 저장한 조합 → 내 번호 → 저장한 설정 순서이며, 첫 진입은 복권 용지이다.
- 내 번호는 공식 컬러 원형 표시를 사용하고, 삭제 대상 선택은 외곽 테두리와 접근성 선택 상태로 구분한다.
- 저장한 조합은 추천 결과와 같은 공식 컬러 번호 칸을 사용한다. 상시 안내 `조합을 누르면 번호를 수정할 수 있습니다.`를 표시한다. 선택/삭제/용지 만들기 동작은 유지한다.
- 사용자 지정 정렬의 화살표는 가로 한 줄로 배치하고 각각 48dp 이상의 누르기 영역을 유지한다.
- 복권 용지 카드의 버튼 위 여백은 없애고 하단 여백은 6dp로 줄인다. 버튼의 누르기 높이는 유지한다.
- 기존 용지 편집은 `편집한 내용 저장`, 신규 용지는 `복권 용지 저장`을 사용한다.

## 물음표 설명

중앙 대화상자 대신 물음표 주변의 작은 설명 상자를 표시한다. 자동 종료·배경 어둡게 처리는 없고, 설명 안 터치는 유지하며 바깥 터치/뒤로가기로 닫는다. 긴 설명은 상자 내부 스크롤로 읽는다. 닫으려고 누른 터치가 뒤쪽 버튼까지 실행되지 않게 투명 모달 배리어를 사용한다.

## 추가: 큰 글자에서 버튼 문구 중앙 정렬

일반 화면과 팝업의 버튼 문구 55곳에 `TextAlign.center`를 명시한다. 글자/디스플레이 확대에 따른 여러 줄 문구도 중앙 정렬하며, 문구를 축소하거나 생략하지 않는다. 내비게이션 목록 항목·라디오 옵션의 왼쪽 정렬은 유지한다. 320px 화면과 200~300% 글자 설정에서 크게 보기 하단, 긴 결과 저장 버튼, 이탈 확인 버튼의 줄별 중앙 정렬을 검증한다.

## 다음 기기 확인

1. 테마 선택만으로 앱이 바뀌지 않고 저장 시 적용되는지, 취소 시 기존 테마가 유지되는지 확인한다.
2. 기존 용지의 기본/간격 넓게가 흑백 기본, 카드형이 흑백 카드로 유지되는지 확인한다.
3. 물음표 위치·긴 설명·내부 스크롤·바깥 닫기를 확인한다.
4. 한/두 자리 원형 크기, 중앙 정렬, 세로/가로 및 OS 확대·임시 확대에서 줄 배치를 확인한다.
5. 새 보관함 순서, 내 번호 선택 삭제, 조합 편집과 컬러 표시, 가로 정렬 화살표와 용지 카드 간격을 확인한다.

기존 `0.1.3-preview` APK에는 이 변경이 포함되어 있지 않다.
