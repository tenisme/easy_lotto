2026-11-05 기준.

- 순수 Dart 추천 모델과 엔진: 고정수, 제외수, 홀짝, 고저, 총합, 연속 묶음, 직전 회차 제외, 미출현 개수 검사 구현.
- 일반 조건에서는 균등 무작위 후보를 선택하고, 1,000회 후보 생성으로 충분한 게임을 얻지 못하면 전체 탐색과 reservoir sampling으로 전환한다. 반복 한도 도달만으로 불가능하다고 판단하지 않는다.
- Flutter 기본 화면: 추천 홈의 1~5게임 선택 → 완전 랜덤 생성 → 추천 결과 → 재생성 확인·취소 연결. 생성은 `compute`를 통해 호출한다.
- 상세 설정 UI: 임시 설정으로 고정수·제외수·홀짝·고저·총합·연속 묶음을 입력하고 결과를 생성한다. 결과에서 설정을 수정하거나 같은 설정으로 다시 생성할 수 있다. 연속 묶음 하위 값은 화면 안에서 옵션을 전환해도 유지한다.
- 공식 XLSX의 1~1248회 기록을 `assets/draws.json`에 포함했다. 최초 오프라인 실행에서도 사용할 수 있고 최근 100회 미출현 기간 선택이 가능하다. 시작 시 기존 캐시와 병합하며 과거 기록은 번들 기준, 새 회차는 캐시 기준으로 보존한다. 갱신은 주간 제한 아래 누락된 새 회차만 조회한다.
- 회차 기록을 포함한 로컬 데이터는 SQLite에 저장한다. 이전 SharedPreferences 데이터는 최초 한 번 이관하고 원본은 보존한다. Android 인터넷 권한과 동행복권 출처 링크를 연결했다.
- 설정 이름 저장·자동 이름·중복 방지·이름 변경을 연결했다. 저장 후 편집 화면을 유지하며 홈의 선택 목록에서 저장 설정을 선택해 수정 또는 바로 생성할 수 있다. 마지막 선택 ID를 복원한다. 결과는 생성 당시 옵션을 유지하고 저장한 설정과 달라지면 변경 안내를 표시한다.
- 설정·회차·보관함은 SQLite의 개별 테이블에 저장한다. 결과 번호 아래 정렬된 하트로 내 번호를 저장하고 조합 전체를 별도로 저장한다. 동일 조합은 중복 저장하지 않으며 저장 요청은 순서대로 반영한다. 홈의 보관함 버튼에서 내 번호·저장한 조합을 조회하고 조합 삭제를 확인 후 수행한다.
- 편집 화면 뒤로가기는 저장되지 않은 변경이 있을 때 확인한다. 결과 뒤로가기는 미저장 게임 또는 임시 설정이 있을 때 확인하며, 설정 편집 진입은 확인 없이 결과를 보존한다. 재생성은 미저장 게임이 있을 때만 확인한다. 저장된 숫자·조합은 결과 이탈 후 유지한다.
- 복권 용지 생성·이름·최대 5게임·추가·제거·교체 전후 확인·위로 이동을 연결했다. 결과에서 게임을 모두 기본 선택하고 필요한 게임을 해제한 뒤 새 용지 또는 빈 칸이 충분한 기존 용지에 넣을 수 있다. 임시 게임은 저장한 조합에 추가하지 않으며 용지에 별도 번호 사본을 저장한다.
- 보관함의 복권 용지 탭에서 만들기·편집이 가능하다. 게임 추가는 저장한 조합을 선택하거나 직접 선택·내 번호·완전 랜덤·상세 설정의 네 경로를 사용한다. 랜덤과 상세 설정 모두 1게임만 만들고 미리보기를 다시 생성할 수 있다. 저장 실패 시 편집 상태는 유지한다.
- 복권 용지 목록 카드 하단의 `번호 크게 보기`를 연결했다. 용지 번호를 A~E 게임으로 표시하며 기본·간격 넓게·카드형을 제공한다. 작은 화면·큰 글자는 줄바꿈과 스크롤로 수용한다.
- 보기 스타일은 전역 기본·용지별·열 때마다 랜덤 모드를 저장한다. 용지 지정이 없으면 기본값을 사용하고, 랜덤은 화면 진입 시 한 번 선택한다. 랜덤 모드 중 기존 기본·용지 지정은 보존되고 편집만 비활성화한다. 최초 안내는 실제 보기 화면 진입 후 한 번 표시한다.
- 화면 계속 켜기는 보기 화면에서 선택적으로 적용하며 화면 이탈·앱 백그라운드·스타일/용지 편집 진입 시 해제한다. 실제 기기에서 플러그인 동작은 별도 검증이 필요하다.
