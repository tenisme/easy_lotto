# 2026-11-09 배지·간격·보관함 작업 영역 개선

사용자의 17개 피드백과 후속 확정 사항을 반영한다. 이 문서는 충돌하는 부분에 한해 [이전 UI 수정](ui-revision-2026-11-08.md)보다 우선한다. 후속 APK·GitHub 업로드 요청에 따라 `0.1.6-preview`(versionCode 7)를 생성·다운로드 검증했다. 기존 `0.1.5-preview` APK에는 이번 변경이 없다. 빌드·다운로드 검증 결과는 [기기 확인 안내](android-device-checklist.md)를 따른다.

## 번호 영역과 하트

- 콘텐츠 가용 폭 기준으로 세로는 좌 7.5% / 번호 영역 85% / 우 7.5%, 가로는 좌 17.5% / 번호 영역 65% / 우 17.5%이다. 회전 시 MediaQuery의 화면 방향으로 판단하며 번호 사이 간격도 영역 폭에 맞춰 늘린다.
- 추천 결과, 보관함의 번호, 복권 용지 편집·크게 보기, 조합 추가와 새 번호 추가 팝업이 공통 영역 컴포넌트를 사용한다.
- 6개 게임 번호의 확대 줄바꿈 정책은 기존 6 / 4+2 / 3+3 / 2+2+2 / 1씩 6줄을 유지한다. 각 줄의 칸 크기와 간격은 동일하고 짧은 마지막 줄도 중앙 정렬한다.
- 45개 선택 번호는 일반 줄바꿈을 사용한다. 각 행을 중앙 정렬하고 배지·선택 테두리를 포함한 칸 크기로 줄 수를 계산한다.
- 하트는 저장한 내 번호, 바깥 테두리는 현재 선택을 뜻한다. 강조색 원형 배지에 흰색 하트를 표시하며 배지 테두리도 같은 강조색으로 한다. 흰색 대비가 부족한 테마에서는 배지·선택 테두리 강조색을 함께 조정한다.
- 배지 지름은 번호 원 지름의 46%로, 이전 제안의 40%보다 약 15% 크게 적용한다. 배지를 셀 안에 배치하며 얇은 그림자로 배경과 구분한다. 사진·배경과 같은 색으로 가장자리를 덧칠하지 않는다.

## 조합 추가

- 세로: 직접 선택은 전체 폭, 다음 줄에 완전 랜덤·상세 규칙을 2분할한다.
- 가로: 직접 선택·완전 랜덤·상세 규칙을 한 줄 3분할한다.
- 별도의 내 번호 모드는 제거한다. 직접 선택의 1~45개 번호 위에 저장한 내 번호의 하트 배지를 표시한다. 6개가 꽉 찼어도 선택된 어떤 번호든 해제할 수 있다.
- 세로에서는 선택한 조합 제목 아래, 가로에서는 제목 오른쪽에 번호를 표시한다. 중앙에 놓인 여섯 자리 영역을 왼쪽부터 채워 추가·해제 때 묶음 전체가 재정렬되지 않게 한다. 실제 번호는 오름차순이다.
- 기존 완전 랜덤·상세 규칙의 1게임 생성·다시 생성·설정 편집 동작은 유지한다.

## 보관함과 고정 작업 버튼

- 조합 카드는 첫 줄에 기존 선택 안내와 같은 기본 글자 양식의 추첨 방식, 오른쪽에 체크박스를 표시한다. 사용자 지정 정렬 시 체크박스 왼쪽에 이동 화살표를 둔다.
- 개별 조합 휴지통·하단 추첨 방식·내부 가로 구분선 두 개는 제거한다. 번호 줄은 편집 진입, 체크박스는 용지 만들기·일괄 삭제 대상 선택으로 구분한다.
- 통합 탭에서만 조합 작업 영역을 목록 아래에 고정하여, 루트 하단 내비게이션 위에 남도록 한다. 세로는 추가·선택한 조합 삭제 버튼 한 줄과 용지 만들기 다음 줄, 가로는 세 버튼 한 줄이다.
- 선택한 조합 삭제는 확인 후 한 번의 저장 작업으로 처리한다. 취소하면 선택과 데이터가 유지되며 복권 용지에 복사한 번호에는 영향을 주지 않는다.
- 큰 글자로 작업 영역 높이가 커지면 해당 영역 내부 스크롤을 제공하여 목록과 버튼이 서로 넘치지 않게 한다.
- 내 번호 삭제 버튼 옆에 번호 추가 버튼을 둔다. 두 버튼은 보관함 번호 영역 안에 있고, 조합 작업 영역만 하단에 고정한다.
- 저장한 조합 제목 위 구분선 아래 여백은 상단 탭에서 내 번호 제목으로 이어지는 기본 여백에 맞춰 늘린다.

## 번호 추가 팝업

- 세로 최대 5열, 가로 최대 9열이다. 폭과 글자 확대에 따라 4열·3열·2열·1열로 줄이며 45개 번호 전체를 세로 스크롤로 볼 수 있다.
- 팝업 최대 폭은 840dp, 최대 높이는 화면 높이의 85%이며 화면 바깥에 16dp 여백을 둔다. 번호 영역의 회전별 85%/65% 정책도 적용한다. 취소·확인 버튼은 번호 스크롤과 별개로 아래에 둔다.
- 기존 번호는 하트로 표시하고 재선택을 막는다. 새 번호를 하나 이상 선택해야 확인할 수 있다. 확인 전에는 저장 내용을 바꾸지 않고, 확인 후 일괄 합집합 저장한다. 범위가 잘못된 번호가 섞이면 전체 작업을 거절한다.

## 간격·헤더

- 추천 결과 카드의 외부 세로 마진 4dp → 8/3dp, 내부 세로 패딩 16dp → 32/3dp로 줄인다.
- 상세 규칙 설명 → 설정 선택 → 버튼 사이의 24dp 간격은 각각 16dp로 줄인다.
- 복권 용지 선택 물음표의 두 문장 사이는 빈 줄 없는 한 번의 줄바꿈으로 바꾼다.
- 조합 카드와 복권 용지 편집의 제목·번호 줄 주변 세로 여백을 줄인다.
- 사용자 지정 순서 안내의 바로 위·아래 간격은 모든 목록에서 각각 16dp이다.
- 큰 글자에서 정렬 선택 문구가 가로로 넘치지 않도록 가용 폭 안에서 줄바꿈하고 항목 높이를 내용에 맞춘다.
- 복권 용지 카드의 이동 화살표는 별도 틈 없이 휴지통 버튼 왼쪽에 붙이고, 48dp 누르기 영역은 보존한다. 휴지통은 공통 테마의 error 색을 사용한다.
- 보관함 카드의 텍스트 왼쪽은 12dp, 아이콘 묶음 바깥 패딩은 0으로 하여 아이콘 자체 여백과 하단 버튼의 가장자리를 맞춘다. 저장한 설정에서도 같은 정책이다.
- 보관함 탭은 가운데 정렬·굵은 글자이며 좁은 폭에서는 스크롤한다. 모든 화면의 상단 제목을 굵게 표시하고 더보기 제목에도 적용한다.
- 복권 용지 정렬 아래에 `용지 이름을 누르면 내용을 수정할 수 있습니다.`를 표시한다.
- 디자인 적용 방식 목록 아래 간격은 24dp이며 각 제목/설명과 첫 라디오 목록 사이에는 12dp를 둔다.

## 검증과 다음 기기 확인

로컬 검증 결과: 정적 분석 이상 없음, 전체 자동 테스트 106개 통과, Dart 포맷 및 `git diff --check` 통과. CI에서도 정적 분석·106개 테스트·APK 빌드가 성공했다. 다운로드한 ZIP과 APK의 무결성·패키지·버전·서명·정렬을 확인했으며, 실제 기기 설치·실행은 다음 확인 대상이다.

자동 테스트는 회전별 번호 폭과 간격, 배지 색·크기·흰색 대비, 팝업의 5열/9열/확대 감소, 번호 추가 후 재로드, 삭제 취소 및 용지 스냅샷 보존, 하단 고정 버튼, 가득 찬 조합의 교체, 안정적인 미리보기 위치, 안내 간격, 큰 글자·좁은 가로 화면을 확인한다.

다음 APK에서는 실제 배지 크기, 세로·가로의 번호 간격, 고정 버튼 높이와 오터치, 팝업 선택·취소, 기존 데이터 보존을 확인한다. 자동 테스트는 실제 기기에서의 시각적 확인을 대신하지 않는다.
