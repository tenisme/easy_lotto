# 2026-11-08 기기 검토 후 UI 수정

후속 배지·간격·조합 카드 변경은 [2026-11-09 수정](ui-revision-2026-11-09.md)을 우선한다. 아래 기록과 `0.1.5-preview` APK는 후속 변경 전 상태이다.

사용자가 38개 수정 사항과 후속 답변, 조합 카드 시안을 승인한 범위이다. 이 문서는 이전 [배치 검토](layout-review.md)와 충돌하는 부분에서 우선한다. 후속 APK 요청에 따라 `0.1.5-preview`(versionCode 6)를 생성·검증했다. 기존 `0.1.4-preview` 다운로드에는 이번 변경이 없다. 빌드 검증 결과와 다운로드는 [기기 확인 안내](android-device-checklist.md)를 따른다.

## 보관함과 정렬

- 탭은 `복권 용지 / 내 번호·조합 / 저장한 설정`이다.
- 통합 탭 상단의 내 번호는 기본 펼침이다. 접힘·펼침을 `library.favoritesExpanded.v1`에 저장하여 재방문과 앱 재실행 후 복원한다. 번호·조합 저장 형식과 데이터는 그대로 유지한다.
- 조합 직접 추가 → 선택 조합으로 복권 용지 만들기 → 정렬 → 중앙 정렬 편집 안내 → 조합 목록 순서이다. 새 복권 용지·새 설정도 테두리 또는 채움 버튼으로 표시한다.
- 정렬 문구는 `최신 등록 순 / 오래된 등록 순 / 이름 순 / 이름 역순 / 사용자 지정 순서`이다. 이름이 없는 조합 목록에는 이름 관련 두 항목을 제공하지 않는다.
- 이름 순은 선행 공백을 무시하고 첫 문자 기준으로 특수기호·문장부호(이모지 포함), 숫자, 한글, 영어, 기타 언어 순이다. 범주 안에서는 영문 대소문자를 구분하지 않고 숫자 묶음을 자연 정렬한다(설정2 → 설정10). 이름 역순은 전체 순서의 역순이다. 별도의 국가별 사전식 정렬은 아니다.
- 정렬 아래에는 16dp 여백을 둔다. 기존 정렬 키와 사용자 지정 순서를 보존하며 새 역순 값만 추가한다.

## 승인한 조합 카드

- 첫 줄: `이 조합 선택`과 우측 체크박스.
- 둘째 줄: 전체 가용 폭을 쓰는 컬러 번호 칸. 번호를 누르면 편집한다. 체크박스 선택과 편집은 분리한다.
- 마지막 줄: 조합 종류, 위치 이동 화살표 묶음, 휴지통 순서이다. 종류 글자는 18sp이다.
- 화살표는 카드 내부, 휴지통 바로 왼쪽에 둔다. 승인 시안보다 조금 가깝게 배치하되 작업 영역 사이에 4dp 여유를 둔다. 두 화살표는 가로 배치하고 누르는 영역은 각각 48dp로 유지한다.
- 복권 용지는 휴지통 왼쪽, 저장한 설정은 더보기 아이콘 왼쪽에 같은 화살표를 둔다.

## 번호 칸과 확대

- 새/기존 용지 편집, 조합 선택, 조합 추가, 실시간 선택 조합 미리보기에도 공식 구간별 컬러 원형 칸을 사용한다. 교체 확인 팝업의 변경 전·후 비교 문장은 텍스트를 유지한다.
- 용지 편집의 게임 이름은 크게 보기와 같은 A~E이다. 추천 결과의 게임 1~5는 유지한다.
- 크게 보기의 번호는 일정한 칸 크기·8dp 간격의 한 묶음을 중앙에 배치한다. 화면이 넓다고 칸 사이를 늘리지 않는다. 작은 목록용 번호는 4dp 간격이다.
- 크게 보기의 줄 배치는 `6 / 4+2 / 3+3 / 2+2+2 / 1+1+1+1+1+1`이다. 두 칸도 못 담으면 한 칸씩 여섯 줄로 표시한다. 가로 스크롤은 제거한다.
- 한 칸조차 담을 수 없는 극단적인 테스트 폭에서는 마지막 안전장치로 칸과 내부 글자를 가용 폭 안에 맞춘다. 보통은 글자 크기를 유지하고 줄 수부터 늘린다.
- 조합 추가의 번호 선택·미리보기는 일반 Wrap을 사용하여 가용 폭에 따라 하나씩 다음 줄로 넘어간다. 선택 조합은 오름차순으로 즉시 갱신한다.
- 텍스트 선택 칸은 체크 표시 없이 동일 크기의 사각형·중앙 정렬 문구로 표시한다. 조합 추가의 네 경로는 기본 2×2 배치이다. 실제 체크박스와 라디오 버튼은 유지한다. 삭제 기능이 있는 사용자 지정 기간 칩은 삭제 버튼을 유지한다.

## 디자인 설정

- 상단은 굵은 20sp `디자인 적용 방식` 한 줄이다.
- 기본 선택 시 `기본 디자인 선택`과 `기본 디자인은 모든 용지에 기본적으로 적용됩니다`, 기본 디자인 선택지만 표시한다.
- 용지별 선택 시 `용지별 디자인 선택`과 `이 용지에만 적용되는 디자인을 선택합니다. 개별 지정이 없는 용지는 기본 디자인을 사용합니다.`, 해당 용지 선택지만 표시한다.
- 랜덤 선택 시에만 굵은 20sp `랜덤 디자인 적용 영역`과 전체/현재 용지 선택지를 표시한다. 이전 값 유지에 관한 상시 문구는 제거한다. 전체 랜덤에서 현재 용지로 바뀌는 범위 안내는 유지한다.
- 각 모드의 저장되지 않은 선택값도 다른 모드로 전환했다고 초기화하지 않는다. 기존 기본·개별 디자인 및 랜덤 복원 정책은 유지한다.
- 예시 위에 24dp 여백과 굵은 20sp `번호 칸 디자인 예시` 제목을 둔다.
- 라디오 목록의 불필요한 세로 여백은 줄이되, 큰 글자 줄바꿈과 누르기 영역은 유지한다.

## 추천·더보기·테마

- 추천: 게임 수 → 번호 생성 방식 제목 → 가로 2분할 선택지 → 선택한 방식 설명 카드 → 저장 설정 선택(상세 규칙만) → 생성 버튼 → 넉넉한 여백 → 중앙 정렬 회차·출처이다.
- 가로 화면에서는 게임 수 제목과 숫자 선택을 한 줄에 배치한다. 최상단 보관함 아이콘을 제거한다. 가로 하단 내비게이션 높이는 80dp에서 68dp로 줄인다.
- 더보기: 앱 테마 설정 → 왼쪽 정렬 결과 이탈 안내 다시 켜기 → 얇은 구분선 → 로또 번호 추천 안내·저장 안내 순서이다. 두 안내 제목만 굵게 표시하고 회차·출처는 제거한다.
- 앱 테마는 선택 후 저장해야 적용한다. 뒤로가기는 경고 없이 초안을 버리고 기존 테마를 유지한다.
- 최초 크게 보기 안내: `이 화면은 저장한 복권 번호를 실제 종이 복권에 옮겨 적기 편하도록 만들어진 화면입니다.` 기존의 한 번만 안내하는 정책은 유지한다.

## 다음 실기기 확인

로컬 검증: Flutter 정적 분석 이상 없음, 전체 자동 테스트 95개 통과. 신규 검증은 이름 분류·역순 저장, 접힘 상태 복원, 승인 카드 배치와 선택/편집 분리, 디자인 하위 영역 조건부 표시, 넓은 화면의 번호 간격, 조합 미리보기 갱신, 용지 게임 이름, 추천·더보기 배치를 포함한다.

1. 기존 번호·조합·용지·테마·디자인·정렬 데이터가 유지되는지 확인한다.
2. 통합 탭의 번호 접힘 상태가 다른 화면 방문과 앱 재실행 후에도 유지되는지 확인한다.
3. 세 목록에서 사용자 지정 순서를 바꾸고 재실행한다. 화살표와 삭제/더보기의 오터치 여부를 확인한다.
4. 조합 카드 체크박스는 선택만, 번호는 편집만 실행하는지 확인한다.
5. 용지 편집·조합 추가의 컬러 원과 A~E 이름, 선택·해제 시 미리보기 갱신을 확인한다.
6. 세 디자인 적용 방식에 맞는 하위 항목만 보이는지, 랜덤 범위와 이전 디자인이 보존되는지 확인한다.
7. 세로·가로·태블릿 폭 및 OS/임시 최대 확대에서 번호 묶음 중앙 정렬과 1열 전환, 스크롤을 확인한다.
8. 추천 배치와 회차·출처 위치, 더보기 정리, 저장하지 않은 테마에서 경고 없는 뒤로가기를 확인한다.
