# 1차 실기기 수정 확정 사항

기준: 사용자 제공 `1차 수정안.pdf` 4쪽 및 후속 확인 답변(2026-11-05).
이 문서의 변경은 기존 화면 문서보다 우선한다. 미언급 항목은 사용자 실기기 확인 결과 정상이다.
2차 APK는 별도 요청 후 생성한다. 기존 APK에는 이번 변경이 포함되어 있지 않다.

## 결과 저장

- 화면·생성 방식 이름 `상세 설정`을 `상세 규칙`으로 바꾼다. `설정 이름`, `설정 저장`, `설정 수정`은 유지한다.
- 결과 카드 우측 상단 체크박스로 게임을 고른다. 전체 기본 선택, 0개 선택은 저장 비활성, 1게임은 선택 절차 생략이다. 별도 게임 선택 팝업은 없앤다.
- 하단 버튼은 `선택한 게임 복권 용지에 저장`이다.
- 같은 결과 화면에서 용지에 저장 완료한 게임은 `저장됨`으로 표시하고 재선택을 막는다. 취소·실패 시 잠그지 않는다. 새 결과를 생성하면 선택 상태를 초기화한다.
- 잠금은 결과 화면 세션에만 적용한다. 보관함에서 같은 조합을 여러 용지에 의도적으로 사용하는 것은 허용한다.
- 대상 선택 제목은 `복권 용지 선택`, 신규 항목은 `새 복권 용지 만들기`이다. 5게임 용지는 제외하고 남는 자리가 부족한 용지는 비활성화한다.
- 물음표 안내: `기존 복권 용지에 남는 자리가 없는 경우, 선택한 게임 수를 줄이거나 새 복권 용지를 만들어 주십시오.`
- 결과 저장 경로의 용지 편집에서는 선택 게임을 교체·제거·추가하지 않는다. 순서와 이름은 바꿀 수 있다. 저장 버튼은 `복권 용지 저장`이다.
- 보관함 용지 편집에서는 교체·제거·추가를 유지한다. 현재 게임과 같은 번호의 교체는 비교 확인창 전에 차단한다.

## 설정과 조합 편집

- 생성 조건을 만족하는 게임이 없으면 상세 규칙 화면을 유지하고 오류를 표시한다. 요청 게임 수도 충족하는지 확인한다.
- 저장된 설정의 변경 저장은 덮어쓰기 확인을 표시한다. 취소하면 초안과 원본을 유지한다. 저장 후 화면은 이동하지 않는다.
- 조합 추가 네 경로는 직접 선택·내 번호·완전 랜덤·상세 규칙이다. 각 경로에서 번호 목록을 표시한다. 숫자 칩은 체크 표시 없이 색상으로만 선택을 나타낸다.
- 랜덤·상세 규칙은 1게임만 생성한다. `선택한 조합`은 다시 생성 버튼 위에, 상세 규칙에는 `설정 수정`을 항상 표시한다.
- 조합 추가 안의 설정 편집은 `설정 완료` 버튼을 사용한다. 미저장 변경은 `저장하고 나가시겠습니까?`와 `저장하지 않음`·`저장하고 나가기`로 확인한다. 이름 입력이나 저장을 취소·실패하면 편집을 유지한다.
- 일반 설정 화면은 여전히 `번호 생성`을 사용한다.

## 미출현 기간과 정렬

- 최근 1·5·10회 빠른 선택과 직접 입력을 제공한다. 직접 입력 범위는 최근부터 연속해서 확보한 회차 수까지다. 엔진의 임의 100회 상한을 제거한다.
- 직접 입력한 기간은 즉시 선택하고 저장하여 다른 설정 편집에서도 재사용한다. 사용자 추가 버튼은 ×로 삭제한다. 현재 선택 삭제 시 최근 5회로 돌아간다. 삭제는 기존 저장 설정의 기간을 바꾸지 않는다.
- 조합·용지·설정 목록에 등록순(최신/오래된 순)과 사용자 지정 순서를 제공한다. 이름이 있는 용지·설정에는 숫자를 고려한 이름순도 제공한다(설정2 → 설정10).
- 사용자 지정 순서는 위·아래 화살표로 조정하고 목록별로 보존한다.

## 크게 보기와 안내

- 기본 모드는 공통 기본 디자인만, 용지별 모드는 현재 용지 디자인만 편집한다. 미지정 용지는 기본값을 따른다. 랜덤 모드는 편집을 막되 이전 값을 지우지 않는다.
- 원형·카드형 숫자를 가로·세로 중앙 정렬한다.
- 화면 계속 켜기 선택값은 앱 설정으로 보존하여 뒤로 나갔다 다시 열어도 복원한다. 실제 효과는 크게 보기 화면이 보일 때만 적용하며 편집·스타일 설정 진입·백그라운드·화면 이탈에서는 해제한다.
- 결과 소실 안내에 다시 보지 않기를 제공한다. 결과 이탈·재생성에만 적용하며 임시 설정 소실·덮어쓰기·삭제 확인은 생략하지 않는다. 더보기에서 다시 켤 수 있다.
- 더보기 출처는 가로로 긴 버튼으로 공식 사이트에 연결한다. `N회 기준`만 표시한다. 추천 안내와 내부 저장·앱 삭제 주의·향후 내보내기/가져오기·클라우드 연동 안내를 표시한다.

## 2차 기기 회귀 확인

1. A·B 용지에 서로 다른 디자인을 지정해 번갈아 열고, 미지정 C가 기본값을 따르는지 확인한다. 랜덤 왕복 후 지정값이 살아 있어야 한다.
2. 화면 켜기를 켜고 뒤로 나갔다 재진입·앱 재실행한다. 토글은 켜져 있지만 화면 밖에서는 실제 효과가 해제되어야 한다.
3. 5게임 중 일부만 저장한다. 완료한 카드만 잠기며 나머지를 다른 용지에 저장할 수 있어야 한다. 취소한 저장은 잠기지 않아야 한다.
4. 설정 변경 저장을 취소·승인하고, 불가능한 조건 생성 후 같은 화면에서 바로 수정한다.
5. 조합 추가 네 경로, 설정 완료의 두 선택, 같은 번호 교체 차단을 확인한다.
6. 기간 직접 입력의 범위·재진입·삭제, 세 목록의 정렬·사용자 순서 복원을 확인한다.
7. 결과 소실 안내의 생략·재활성화가 다른 확인창까지 생략하지 않는지 확인한다.

기존 미수정 기능은 1차 확인을 존중하되 변경 경로와 연결되는 부분은 회귀 확인한다.
