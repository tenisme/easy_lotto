## 보관함 정보 구조

보관함 상단에는 다음 네 범주를 가로 탭으로 제공한다.

1. `내 번호`: 추천 결과에서 하트로 저장한 개별 숫자
2. `저장한 조합`: 추천 또는 직접 입력으로 저장한 번호 6개 조합
3. `복권 용지`: 1~5개 게임을 묶어 저장한 구매 참고용 용지
4. `저장한 설정`: 이름을 붙여 저장한 추천 조건

탭이 작은 화면에 모두 들어가지 않으면 가로 스크롤을 허용한다. 현재 탭과 선택 상태는 색상 외에도 굵기와 밑줄로 구분한다.

## 내 번호

- 저장한 숫자를 원형 칩과 저장 상태 아이콘으로 표시한다.
- `편집`에서 여러 숫자를 선택해 한꺼번에 삭제할 수 있다.
- `상세 설정 열기`는 고정수 선택 화면으로 이동하고 내 번호를 불러올 수 있게 한다.
- 저장한 숫자가 없으면 추천 화면으로 이동하는 빈 상태 안내를 표시한다.

## 저장한 조합

- 각 행에 번호 6개, 생성 출처와 추가 메뉴를 표시한다.
- `직접 추가`에서 1~45 중 정확히 6개를 골라 저장한다.
- 선택 모드에서는 1~5개 조합을 골라 `복권 용지 만들기`를 실행할 수 있다.
- 동일한 번호 6개 조합은 중복 저장하지 않는다.
- 삭제는 확인 후 수행하며, 해당 조합으로 이미 만든 복권 용지는 영향을 받지 않는다.

## 저장한 설정

- 설정 이름과 주요 활성 조건을 요약해 표시한다.
- 각 설정에서 수정, 이름 변경, 복제와 삭제를 제공한다.
- 최근 사용한 설정은 보조 배지로 표시할 수 있다.
- `새 설정`은 빈 상세 설정 화면으로 이동한다.

## 복권 용지

- 목록 카드에는 용지 이름, 게임 수, 저장일과 간단한 번호 미리보기를 표시한다. 카드 하단에는 가로로 긴 `번호 크게 보기` 버튼을 둔다.
- 편집 화면에서 용지 이름, 게임 추가·제거·교체와 순서를 변경한다.
- 새 용지의 이름 입력칸에는 `복권 용지 N`을 미리 채운다. N은 현재 사용되지 않은 가장 작은 양의 정수이며 이름은 바로 수정할 수 있다.
- 한 용지에는 최대 5개 게임만 저장한다.
- 빈 슬롯에는 `조합 추가`를 표시한다.

### 번호 스냅샷 정책

복권 용지에 조합을 추가할 때 번호 6개를 별도로 복사한다. 이후 원본 저장 조합을 수정하거나 삭제해도 기존 용지의 번호는 바뀌지 않는다.

용지의 게임을 교체할 때는 현재 번호와 바꿀 번호를 함께 보여주고 다음 문구를 표시한다.

> 이 용지의 게임만 바뀌며, 저장한 원본 조합은 변경되지 않습니다.

`교체`를 누르면 다음 순서로 진행한다.

1. `바꿀 조합 선택` 바텀 시트에서 저장한 조합을 라디오 목록으로 확인한다.
2. 필요한 조합이 없으면 `조합 추가`로 이동한다. 이 화면에서는 `직접 선택`, `내 번호`, `완전 랜덤`, `상세 설정` 중 하나로 번호 6개를 완성하고 `복권 용지에 추가`를 누른다. 이 번호는 저장한 조합에 자동 저장되지 않는다.
3. 조합 하나를 선택하고 `다음`을 누른다.
4. 새 조합을 만든 경우에는 `복권 용지에 추가`를 누르면 현재 번호와 바꿀 번호 비교 화면으로 바로 이동한다. 비교 후 `교체`를 눌러 확정한다.

### 조합 추가의 네 가지 경로

`조합 추가` 화면 상단에는 다음 네 경로를 2×2 선택 카드로 제공한다. 교체 바텀 시트에서 이미 `저장한 조합`을 고를 수 있으므로 이 화면에서 같은 목록을 다시 제공하지 않는다.

1. `직접 선택`: 1~45 숫자판에서 정확히 6개를 선택한다.
2. `내 번호`: 저장한 개별 숫자를 먼저 보여준다. 원하는 숫자를 선택한 뒤 부족한 개수는 전체 숫자판에서 채운다.
3. `완전 랜덤`: 조건 없이 정확히 1게임을 만들며 미리보기에서 다시 생성할 수 있다.
4. `상세 설정`: 저장한 설정을 선택하거나 임시 설정을 만든 뒤 정확히 1게임만 생성한다. 상세 설정의 고정수 선택에서는 기존과 동일하게 `내 번호`를 불러올 수 있다. 생성된 번호는 `조합 추가` 화면의 미리보기에 채우며 자동 저장하지 않는다. 미리보기 아래의 `다시 생성`을 누르면 현재 설정을 그대로 사용해 1게임을 새로 만든다.

네 경로 사이를 이동해도 현재 완성한 번호는 사용자가 새 번호로 교체하기 전까지 유지한다. 마지막 단계의 버튼은 `복권 용지에 추가`로 한다. 누르면 번호 6개를 해당 용지의 게임 스냅샷으로 복사하며 `저장한 조합`에는 추가하지 않는다. 게임 교체 중이라면 바로 저장하지 않고 교체 전후 비교 화면으로 넘긴다.

복권 용지 생성과 편집에는 저장된 조합과 저장하지 않은 임시 조합을 모두 사용할 수 있다. 사용자가 같은 번호를 별도로 보관하고 싶다면 추천 결과 또는 저장한 조합 화면의 독립된 `조합 저장` 기능을 사용한다.

`완전 랜덤`과 `상세 설정`의 미리보기에는 모두 `다시 생성`을 제공한다. 아직 복권 용지에 추가하지 않은 후보를 바꾸는 동작이므로 저장 안내 대화상자는 표시하지 않으며, 기존 용지 게임과 저장한 조합은 변경하지 않는다.

## 번호 크게 보기

- 용지 이름과 게임 수를 표시한다.
- A~E 게임을 크고 단순한 번호 행으로 보여준다.
- 공식 OMR 디자인을 복제하지 않고 번호를 옮겨 적기 쉬운 독자적인 배열을 사용한다.
- `화면 계속 켜기`를 화면에서 바로 켜고 끌 수 있다.
- 화면의 반복 안내 문구는 제거한다.
- 하단의 `보기 스타일`은 전역 보기 방식과 디자인을 선택하는 화면을 연다. 초기 디자인 후보는 `기본`, `간격 넓게`, `카드형`이다.
- `용지 편집`은 해당 용지 편집 화면으로 이동해 번호 구성과 순서를 바꾼다.

처음 `번호 크게 보기`를 누르면 번호 크게 보기 화면으로 먼저 이동한다. 화면이 표시된 직후 그 화면 위에 제목 `번호 크게 보기`와 다음 안내를 한 번만 표시한다.

> 이 화면에서는 저장한 복권 용지를 실제 종이 복권에 편하게 옮겨 적을 수 있습니다.

`확인`을 누르면 대화상자를 닫고 이미 진입한 번호 크게 보기 화면을 그대로 사용한다. 이후에는 같은 안내를 자동으로 표시하지 않는다.

### 보기 스타일 적용 방식

보기 스타일에는 다음 세 가지 적용 방식을 둔다.

1. `기본 디자인`: 사용자가 고른 하나의 디자인을 모든 용지에 공통으로 적용한다. 앱 최초 실행 시에는 앱이 지정한 초기 기본 디자인을 사용한다.
2. `용지별 디자인`: 용지에 개별 디자인이 있으면 이를 적용하고, 지정하지 않은 용지는 마지막으로 저장한 기본 디자인을 적용한다.
3. `열 때마다 랜덤`: `번호 크게 보기`를 새로 열 때마다 사용 가능한 디자인 중 하나를 무작위로 적용한다. 화면을 보고 있는 동안에는 디자인을 바꾸지 않는다.

`열 때마다 랜덤`을 선택하면 기본 디자인 선택과 용지별 디자인 편집을 비활성화하되 기존 선택값은 삭제하지 않는다. 이후 `기본 디자인`을 선택하면 마지막 기본 디자인으로, `용지별 디자인`을 선택하면 마지막 기본 디자인과 각 용지의 마지막 개별 디자인으로 즉시 복원한다.

## 이번 시안에서 확인할 사항

- 보관함의 네 범주를 상단 탭으로 나누는 방식이 이해하기 쉬운가
- 저장한 조합의 선택 모드와 `복권 용지 만들기` 흐름이 자연스러운가
- 저장한 설정을 보관함의 한 범주로 두는 것이 적절한가
- 번호 크게 보기의 한 화면 5게임 표시가 실제 구매 환경에서 충분히 읽기 쉬운가
